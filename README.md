# KBLNK

kblnk-cli is a CLI to interact with LLMs in your terminal.

This tool and its associated crates are under development, and as such, not suitable for production use.

# Model Support

- [x] Google AI Studio
- [ ] Self-hosted
  - [ ] OpenAI API compatible (Such as [llama.cpp](https://github.com/ggml-org/llama.cpp))
